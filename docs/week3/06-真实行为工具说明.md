# 06-真实行为工具说明 —— open_url / send_email

> 分组四 · Tools + OS Skills · "AI 真实行动"第一批工具（L1 系统动作 + L2 邮件）
>
> 一句话：**AI 想真的做事，不是改架构，而是往 ToolRegistry 里注册新工具——安全闸门、参数预检、统计审计自动生效。**

---

## 一、两个新工具

| 工具 | 权限 | 行为 | 安全设计 |
|------|------|------|---------|
| `open_url` | PUBLIC | 系统默认浏览器打开网址 | 仅允许 http/https（javascript:/file: 全拒） |
| `send_email` | **ADMIN** | SMTP 发邮件（465 SSL / 587 STARTTLS 自动选择） | **默认 dry_run=True 只预览不发送**；真实发送需提权 + 凭据 |

## 二、怎么用（三行接入）

```python
from src import ToolRegistry, PermissionLevel
from src.real_tools import register_real_tools

registry = ToolRegistry()
register_real_tools(registry)          # 可选注册，不影响原 8 工具契约

# 干跑（默认）：构建邮件返回预览，不联网
r = registry.call("send_email",
                  {"to": "teacher@school.edu", "subject": "周报", "body": "本周进展……"},
                  user_level=PermissionLevel.ADMIN)
print(r.to_dict())   # {'success': True, 'result': {'dry_run': True, 'to': [...], ...}}

# 真实发送：dry_run=False + 凭据（参数或环境变量）
# SMTP_HOST=smtp.qq.com SMTP_PORT=465 SMTP_USER=xxx@qq.com SMTP_PASS=授权码
r = registry.call("send_email",
                  {"to": "teacher@school.edu", "subject": "周报", "body": "……",
                   "dry_run": False},
                  user_level=PermissionLevel.ADMIN)
```

演示亮点（权限叙事）：以 USER 身份调 `send_email` → 返回"权限不足：需要 admin"→
"请求用户确认" → 提权 ADMIN → 干跑预览 → 确认后真实发送。全程留痕进组 5 审计日志。

## 三、邮箱联调结果（2026-09-04 已实测通过 ✅）

实测结论（QQ 邮箱 SMTP）：

| 端口 | 结果 | 说明 |
|------|------|------|
| 465 SSL | ❌ 连接超时 | 本机网络环境拦了出站 465（非代码问题） |
| **587 STARTTLS** | ✅ **发送成功** | smtp.qq.com:587，login + send_message 正常 |

完整闭环验证：干跑预览 → `dry_run=False` 真实发送 → **IMAP 反向查收件箱确认收到**，
主题/收件人/正文标记全部核对一致。凭据走环境变量注入，未写入任何项目文件。

复现步骤（凭据自备，切勿提交到代码库）：

1. QQ 邮箱：设置 → 账户 → 开启 SMTP 服务 → 生成**授权码**（不是 QQ 密码）
2. 设置环境变量后运行（PowerShell）：
   ```powershell
   $env:SMTP_HOST="smtp.qq.com"; $env:SMTP_PORT="587"
   $env:SMTP_USER="你的QQ号@qq.com"; $env:SMTP_PASS="授权码"
   ```
3. 先干跑确认内容无误 → 再 `dry_run=False` 发送 → 收件箱验证
4. 常见失败对照：`SMTP 认证失败` = 授权码错/未开服务；`网络错误: timed out` = 端口被拦（本机 465 被拦，**换 587**）
