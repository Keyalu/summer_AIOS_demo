## 2. 完整测试套件详解（tests/test_all.py — 31 个）

### 2.1 TestToolRegistry — 15 个测试

这是最核心的测试类，覆盖了工具注册表的所有关键行为。

#### T1: test_default_tools_registered

**验证：** 初始化后 8 个默认工具都已注册。

```python
def test_default_tools_registered(self):
    assert self.registry.has("copy_file")
    assert self.registry.has("move_file")
    # ... 共检查 8 个
```

**为什么重要：** 如果这个失败，说明 `_register_defaults()` 有 bug，组3 启动后一个工具都用不了。

---

#### T2: test_register_custom_tool

**验证：** 动态注册自定义工具并成功调用。

```python
def test_register_custom_tool(self):
    def my_echo(msg: str) -> dict:
        return {"success": True, "result": f"ECHO: {msg}"}

    self.registry.register("echo", my_echo)       # 注册自定义函数
    result = self.registry.call("echo", {"msg": "hello"})
    assert result.success is True
    assert result.result == "ECHO: hello"
```

**为什么重要：** 证明系统是可扩展的——未来可以不修改核心代码就加新工具。

---

#### T3: test_register_duplicate_raises

**验证：** 注册同名工具必须报错。

```python
with pytest.raises(ValueError, match="已注册"):
    self.registry.register("copy_file", lambda: None)
```

**为什么重要：** 防止意外覆盖已有工具。如果 `copy_file` 被覆盖成别的函数，组3 的文件复制就会出问题。

---

#### T4-T5: test_unregister / test_call_nonexistent_tool

**验证：** 注销和错误处理。

```python
assert self.registry.unregister("copy_file") is True    # 注销成功
assert not self.registry.has("copy_file")               # 确实没了
assert self.registry.unregister("copy_file") is False   # 重复注销返回 False

result = self.registry.call("nonexistent_tool", {})
assert result.success is False                          # 不存在的工具返回失败
assert "未注册" in result.error                         # 错误信息清晰
```

---

#### T6: test_permission_admin_required

**验证：** 权限系统拦截高危操作。

```python
# user 级别调 admin 工具 → 被拒
result = self.registry.call("run_command", {"cmd": "echo hi"}, PermissionLevel.USER)
assert result.success is False
assert "权限不足" in result.error

# admin 级别调用 → 成功
result = self.registry.call("run_command", {"cmd": "echo hello"}, PermissionLevel.ADMIN)
assert result.success is True
assert "hello" in result.result
```

**这是安全模型的核心测试！** 如果权限检查有漏洞，非管理员用户可以执行任意命令。

---

#### T7: test_public_permission

**验证：** public 级别工具允许最低权限调用。

```python
result = self.registry.call("list_directory", {"path": "."}, PermissionLevel.PUBLIC)
assert result.success is True
```

证明 `list_directory` 和 `read_file` 这两个只读工具确实不需要认证。

---

#### T8: test_write_and_read_file

**验证：** 文件读写闭环。

```python
with tempfile.TemporaryDirectory() as tmp:
    path = os.path.join(tmp, "test.txt")
    content = "Hello 分组四!"

    r = self.registry.call("write_file", {"path": path, "content": content})
    assert r.success is True

    r = self.registry.call("read_file", {"path": path})
    assert r.success is True
    assert r.result == content        # 写入的内容能原样读回
```

**使用 `tempfile.TemporaryDirectory()`：** 测试完自动清理，不留垃圾文件。

---

#### T9: test_create_and_list_dir

**验证：** 创建目录后能在列表中看到它。

```python
with tempfile.TemporaryDirectory() as tmp:
    sub = os.path.join(tmp, "subdir")
    r = self.registry.call("create_folder", {"path": sub})
    assert os.path.isdir(sub)

    r = self.registry.call("list_directory", {"path": tmp})
    names = [item["name"] for item in r.result["entries"]]
    assert "subdir" in names
```

---

#### T10: test_copy_file

**验证：** 复制后源文件还在，目标文件存在且内容一致。

```python
with tempfile.TemporaryDirectory() as tmp:
    src, dest = f"{tmp}/src.txt", f"{tmp}/dest.txt"
    with open(src, "w") as f: f.write("original")

    r = self.registry.call("copy_file", {"src": src, "dest": dest})
    assert r.success
    assert os.path.exists(src)           # 源文件仍在
    assert os.path.exists(dest)          # 目标文件已创建
    assert open(dest).read() == "original"  # 内容一致
```

---

#### T11: test_move_file

**验证：** 移动后源消失、目标出现。

```python
with tempfile.TemporaryDirectory() as tmp:
    src, dest = f"{tmp}/src.txt", f"{tmp}/moved.txt"
    with open(src, "w") as f: f.write("move me")

    r = self.registry.call("move_file", {"src": src, "dest": dest})
    assert r.success
    assert not os.path.exists(src)       # 源已消失
    assert os.path.exists(dest)          # 目标出现
```

**copy vs move 的区别在这个测试中一目了然。**

---

#### T12: test_delete_file

**验证：** 删除后文件不存在。

```python
with tempfile.TemporaryDirectory() as tmp:
    path = f"{tmp}/delete_me.txt"
    with open(path, "w") as f: f.write("delete me")
    r = self.registry.call("delete_file", {"path": path})
    assert r.success
    assert not os.path.exists(path)
```

---

#### T13: test_call_with_wrong_params

**验证：** 参数名错误时给出清晰的错误提示。

```python
r = self.registry.call("copy_file", {"wrong_param": "value"})
assert r.success is False
assert "参数错误" in r.error               # TypeError → 友好提示
```

**Python 的 `func(**params)` 在参数名不匹配时抛 TypeError，我们捕获后转成友好消息。**

---

#### T14: test_dangerous_command_blocked ⚠️

**验证：** 最危险的操作被黑名单拦截。

```python
r = self.registry.call(
    "run_command",
    {"cmd": "rm -rf /"},                # 最危险的命令
    PermissionLevel.ADMIN,              # 即使是管理员也不行！
)
assert r.success is False
assert "拒绝执行" in r.error
```

**注意：** 即使传了 ADMIN 权限，黑名单仍然生效。权限控制管的是"谁有权调用"，黑名单管的是"什么不能做"。两者独立叠加。

## 5. 从测试看设计质量

### 5.1 测试覆盖率评估

| 模块 | 代码行数 | 测试数 | 覆盖率估计 |
|------|---------|--------|-----------|
| tool_registry.py | ~160 | 15 | ~90% (核心 call/register 全覆盖) |
| default_tools.py | ~275 | 8 (直接) + 15 (间接) | ~85% |
| skill_library.py | ~360 | 7 | ~80% (每个 Skill 至少 1 个 happy path) |
| mcp_connector.py | ~125 | 5 | ~85% |
| stats.py | ~125 | 1 (间接) + Week2 3 | ~75% |
| mock_registry + mock_skills | ~70 | 2 | ~90% (逻辑简单) |

### 5.2 未覆盖的部分（后续可补充）

- **并发安全：** 多线程同时 register/call 同一个工具
- **超大文件：** GB 级文件的 copy/find_duplicate 性能
- **权限边界：** 符号链接、只读文件系统、无权限目录
- **网络文件系统：** NFS/SMB 路径下的操作
- **异常恢复：** 磁盘满、IO 错误等极端情况

对于课程项目来说，当前覆盖率已经足够。以上未覆盖部分属于生产环境才需要考虑的。
